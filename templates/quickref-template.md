# 主题名称

## 组合按键

| 快捷键 | 功能 |
|---|---|
| Ctrl+Key | 功能 |
| Ctrl+Key,  Key | 功能 |

## 常用指令

### 常用参数

| 参数 | 作用 |
|---|---|
| `-x` | 参数作用，长选项为 --example |
| `-y` | 参数作用，长选项为 --another |

### 单行指令

| 示例指令 | 功能 |
|---|---|
| `command --with-arguments` | 指令功能 |
| `command --option value` | 指令功能 |

> -x 为默认参数，示例已省略。

### 多行长指令

指令功能

```bash
command --first-argument \
  --second-argument value
```
